# Strength patterns (exercise selection)

Which exercises to pick, and why. Sets, reps, RIR and load are in `references/strength-prescription.md`; session layout is in `references/strength-session.md`. Goal is durable force and stability, not mass. Confidence tags as defined in `strength-prescription.md` (`[evidence]`, `[consensus]`, `[convention]`).

Equipment column: `FG` = `fullGym`, `HD` = `homeDumbbells`, `BW` = `bodyweight`. Only offer an exercise the athlete's `equipment` allows (`athlete-config.md`); a `bodyweight` athlete uses regressions only. If `equipment` is missing, ask once (SKILL.md Step 1) before selecting.

## Selection rule

A full session is **one K or H main lift + one U + one H or C + one T**, plus **one P** when the target event is an ultra (e.g. `badlands-ultra`). `[consensus]` (the studied core is squat + single-leg press + hip flexion + calf; hinge, trunk and pull work are consensus). Core-only session: 3-4 T moves. Add single-leg hip flexion in max-strength blocks (Base wk 9-12 for `new`, Build/Refine).

**Rotation:** keep one main lift per pattern stable across the phase; swap accessory variants every 3-4 weeks `[consensus]`. Every exercise in the plan gets a stated reason (see the "Why this session" block in `strength-session.md`).

## Tune to the athlete

Lean selection toward what the athlete described. If `physicalNotes` names a specific sensation (lower-back fatigue, power not transferring on climbs), favour the posterior chain and anti-rotation core over the default split; it is a hypothesis from the athlete's own account, worth testing without a data signal. Rider type (Step 2) and the target event's limiters can shift emphasis (more single-leg and core for stability, more posterior chain for power).

**Injury flags** (`strengthInjuryNotes`): substitute or regress the affected exercise rather than prescribing it as written, and say so in the reason line.
- **Lower-back tightness:** trap bar, hip thrust, leg press, split squat, chest-supported row and 45-degree back extension come before barbell back squat and straight-bar deadlift for the **first two blocks**; RIR >=3 on hinge patterns; add posterior-chain endurance (Sorensen holds, bird dog) `[consensus]`.
- **Tight quads / poor knee-flexion tolerance:** leg press with limited depth (knee about 90 degrees), box squat, goblet squat; Bulgarian split squat only if pain-free (else step-up); avoid deep ATG squats and knee-dominant volume spikes early (tendon adaptation lags muscle); quad lengthening only after sessions, never before heavy lifts `[consensus]`.
- **Any other named joint:** regress to the nearest pain-free pattern from the same category.

## K: knee-dominant bilateral

Role: hip and knee extensors generate most downstroke power; half-squat range (knee about 90 degrees) matches the pedalling range better than deep squats `[evidence]` for half squat / leg press as the studied staples.

| Exercise (regression to progression) | Equip | Flags / notes |
|---|---|---|
| Box squat to bodyweight, then goblet squat | BW, HD, FG | Upright torso; box sets depth |
| Leg press (limited depth) | FG | First choice for quad tightness or back flag |
| Trap-bar squat-deadlift | FG | Upright torso, less lumbar shear than straight bar `[consensus]` |
| Safety-bar or half back squat | FG | Only after the first two blocks if a back flag exists |

## U: unilateral

Role: single-leg leg press is a studied staple `[evidence]`; also exposes left-right asymmetry. Step-up at about knee-level box `[consensus]`.

| Exercise | Equip | Flags / notes |
|---|---|---|
| Bodyweight step-up (low box) then loaded step-up | BW, HD, FG | Regression for a knee flag |
| Split squat, then Bulgarian split squat | BW, HD, FG | Front foot elevated only if pain-free |
| Single-leg leg press | FG | Studied protocol lift |
| Single-leg hip flexion (cable or ankle weight, standing), 3 x 6-10 per side | FG | Max-strength blocks; targets the pull-up phase `[evidence]` |

## H: hinge

Role: glute/hamstring and lower-back robustness `[consensus]`; absent from classic cyclist protocols. Bone loading also helps, since cycling is not bone-loading `[consensus]`.

| Exercise | Equip | Flags / notes |
|---|---|---|
| Glute bridge, then hip thrust (3 x 8-12, moderate load) | BW, HD, FG | Hip thrust: low confidence for cycling transfer |
| Romanian deadlift (light dumbbells first) | HD, FG | Hinge from the hips, flat back; RIR >=3 with a back flag |
| Trap-bar deadlift | FG | Preferred over straight bar with a back flag |
| Straight-bar deadlift | FG | Only after the first two blocks with a back flag |
| Back extension (45 degrees) | FG, BW (floor) | Low-back robustness |

## C: calf

Role: ankle stability and force transfer; toe raise is in every Rønnestad protocol `[evidence]` for inclusion, ankle-stiffness rationale `[convention]`.

| Exercise | Equip |
|---|---|
| Straight-knee then bent-knee calf raise (bodyweight, then loaded; single-leg to progress) | BW, HD, FG |

## T: trunk

Role: posture over hours on the bike, anti-extension/rotation, back-extensor endurance `[consensus]` (LBP evidence is not cyclist-specific).

| Exercise | Equip |
|---|---|
| Dead bug, bird dog | BW |
| Side plank (30-45 s per side), plank | BW |
| Pallof press | HD (band), FG (cable) |
| Sorensen hold (30-60 s) | BW, FG |
| Loaded carry (20-30 m) | HD, FG |

## P: pull / upper

Role: posture and handlebar tolerance over long days; low-medium confidence `[consensus]`. Add one P move to full sessions when the target is an ultra; 2 sets of 8-12.

| Exercise | Equip | Notes |
|---|---|---|
| Chest-supported or dumbbell row | HD, FG | Chest-supported preferred with a back flag |
| Lat pulldown | FG | |
| Face pull / rear-delt raise | HD, FG | |
| Push-up or dumbbell press | BW, HD, FG | |

Bike fit and hand-position variety matter more than gym work for numbness and back pain; mention that when the athlete reports either.
