Cycling Plan Coach — Design system

A calm, data-forward look for a coaching app used daily

Warm neutral ground so long reading sessions (plans, logs, trends) don't glare; a deep teal brand color kept out of the status vocabulary so "is this good or bad" is never ambiguous; Sora for headings and big numbers, Public Sans for body text, JetBrains Mono for every measured value (watts, kg, dates, countdowns) so data reads as data.

Form fields

+ a soft dual shadow — never a heavy drop shadow or a colored border for emphasis (use a 1px brand ring instead, as on the "today" card).
Navigation pattern
Desktop ≥ 960px

A persistent 248px sidebar replaces the current six-link text header that wraps unpredictably: brand mark, five destinations with icons, athlete identity and sign-out anchored at the bottom.

Mobile < 960px

The sidebar collapses into a fixed bottom tab bar (Today / Season / Fuel / Strength / Trends) — thumb-reachable, always visible, no header overflow. See the Mobile artboard.

State & feedback

Loading, empty and error states get the same card chrome and typography as real content — never bare unstyled text — so the app never looks broken while it's just waiting on data.
